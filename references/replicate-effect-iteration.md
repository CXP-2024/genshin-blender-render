# 严格复刻参考渲染效果的迭代方法

用户给出参考视频、参考图或另一个角色的效果，要求“一比一”“99%”“几乎一样”时使用。来源是 2026-10-28 至 10-30 的两轮实际工作：《愛包ダンスホール》奥黛塔场景复刻，以及 DeepSeek 闭眼线对齐奥黛塔。

这里记录的是做法，不是成功保证。场景复刻 16 个版本后仍判定“未达到 99%”，闭眼线也还没有合并，见末尾。

## 1. 开工前先核对能拿到什么

先查再做，不要手搓一个近似版本：

- 视频简介和借物表里的模型、动作、镜头、MME、场景。
- 同名 VMD 镜头或动作能否下载。本次镜头文件下载后，视频第 N 帧就是镜头第 N 帧，构图可以逐帧对上。
- 本地已认可的模型和渲染配方。

然后告诉用户三件事：哪些已有，哪些拿不到，因此能做到什么程度。拿不到原始 MME 或场景时，一开始就说明 99% 无法保证，不要等做完才说。

## 2. 先定义“一样”怎么算

- 把目标拆成可检查的项：构图、动作、明暗分界、阴影色、边缘光、描边、景深、泛光、调色、场景。
- 形状类目标（闭眼线、轮廓）写清是整图还是局部，用 2D 外轮廓比，不用 3D 坐标比。
- 用户指出不算的部分要从指标里去掉。例如奥黛塔闭眼线末端的羽毛尖角不计入相似度，DeepSeek 保持平滑。
- 目标之外的硬约束也写下来，例如保持 Charakuru 脸型、不改贴图。

## 3. 先对齐，再比外观

构图和动作没对齐时，比颜色没有意义。按这个顺序：

1. 从参考抽 18 帧左右的总览，再选固定审核帧，覆盖近景、全身、侧面、亮场和暗场，保存为 `ref/ref_<帧号>.png`。
2. 确认参考帧号和工程帧号的关系，并记录偏移（本次 DeepSeek 第 b 帧对应镜头第 b+19 帧）。
3. 镜头用同一 VMD。Blender 里烘焙镜头、去掉 180° 翻转驱动，否则无界面渲染会错。
4. 参考场景无法取得时，用多机位反推尺寸和位置（本次球罩靠两个机位三角测量）。

审核帧一旦选定就不要换。换帧比较出来的“进步”不算数。

## 4. 同角色先复刻，再迁移到目标角色

1. 用参考里的同一角色（奥黛塔）把效果做出来。这样差异只来自渲染，不来自模型。
2. 同角色通过后再迁移到目标角色（DeepSeek）。主光、明暗阈值、阴影色、边缘光和后期共用。
3. 迁移时只在目标材质的“贴图 → 自发光”之间插入节点，不改贴图和网格。
4. 记录哪些迁移了，哪些没有。专用脸部阴影、鼻部遮罩、腮红不能直接抄到 UV 不同的模型。

## 5. 按层迭代，每次只动一层

顺序：几何与镜头 → 灯光 → 材质 → 描边 → 后期 → 场景细节。

- 每轮只改一层或一个因素，保持灯光、相机和审核帧不变。
- 每轮另存新版本，保留前一版，并写下改了什么（`v16_changes.json` 这样的记录）。
- 每轮输出同帧并排图：`python scripts/compare_frames.py cmp.jpg --frames 300,1350 --ref 'ref/ref_{}.png' --test 'renders_v3/f_{}.png'`。
- 多个候选时放在同一张图里比，而不是让用户记住上一张。
- 用整片预览前先用几帧。用户限制 GPU 或要求云端时，遵守当时的约定。

## 6. 形状类目标用量化指标

闭眼线这类细节，肉眼说“差不多”不够。做法：

1. 两边用同一相机、同一表情键，单独渲染放大的遮罩，不要用整张成片。
2. 阈值提取目标形状，去掉细碎噪点，取最大连通块。
3. 以两端点归一化坐标，算上下边缘曲线 v(u)。
4. 算 IoU，以及上边缘、下边缘和厚度分布的误差，并输出叠加图。
5. 端点抖动会让 IoU 不稳定，用最佳对齐后的 IoU。
6. 反向确认：指标升高时也要看图。指标好但画面出现翻折，算失败。

不要把整帧 PSNR、SSIM 当作“与参考相似度”。角色和道具不同，这个数字没有意义。整体观感由用户判断。

## 7. 让用户看准位置

- 用户指定的帧优先，不要自己换一帧找替代。
- 有问题的部位单独放大、完整渲染。
- 同一表情键、同一帧与参考同台对比，并确认用的是用户自己的表情键。
- 用户画了线，就把这条线当作目标。
- 用户说“停下来”，先停，等他们指出具体位置，再继续。

## 8. 何时停，怎么报告

- 修一处冒出另一处（平滑、位置展开、法线翻转都曾露出翻片），就退回上一版换思路，不要继续在错误结果上打补丁。
- 同一方向连续失败时，告诉用户原因和可选项。用户决定暂停就保留现场，不合并半成品。
- 每轮报告分三栏：已经一致、仍不一致、这一版改了什么。
- 没有有效数值时写“未建立数值依据”，不要声称 99%。可以留一个状态文件，例如 `status: review_pending_not_99_percent`。
- 通过判断以用户看图为准。指标只是帮助定位。

## 9. 收尾

- 把认可的参数存成预设，写明来自哪个工程。数值以保存的节点为准，不只靠文字重建。
- 写清这是重建，不是原始 MME。
- 列出未迁移的部分和已知差距。

## 本方法的实际结果

| 工作 | 结果 |
|---|---|
| 奥黛塔场景复刻（Codex，16 版） | 用户接受为可用预设，状态仍是“未达到 99%”，衣料反光、头发辉光、脸部阴影和场景细节仍有差距 |
| 奥黛塔场景复刻（Blender 5.2 重建） | 镜头、动作可逐帧对上，整体氛围接近，道具简化，未达到 99% |
| DeepSeek 使用同一着色 | 主光、阈值、阴影色、边缘光、后期共用；深色衣物偏暗偏油亮，后来单独加了布料组 |
| DeepSeek 闭眼线对齐奥黛塔 | 量化指标已建立，迭代未合并，用户暂停 |
