# 天天天国最终审核版：R9 外观 + R11 混合物理

用户于 2026-10-18 看过全篇预览后要求保存本配方供其他 agent 复现。当前成品为 31.63 秒、1280×720、30 fps、949 帧、AAC 原音乐。不是本轮新做的 4K60；已有旧 4K60 不能当作这次混合物理交付。

## 外观基线

- Blender 4.2.23 LTS，EEVEE Next，48 render samples，透明 RGBA PNG；Morningstar/Festivity 与 mmd_tools 配套环境沿用已验证安装。不要切换 Cycles。
- 直接加载已打包 R9 / R11 场景。材质、灯光、色彩管理、眼睛透明层、MMD 细描边、脸部 SDF 与头部方向驱动保留场景值；不要重新转换或凭摘要重建灯光。
- R9 在 R7 脸部/接收阴影、头发与金属响应基础上，将衣料中 `Review cloth neutral shading*` 的 Hue/Saturation 节点 Saturation 从 0.3 恢复为 1，Value 从 1.02 恢复为 1；`Review cloth broad reflection` 输入上原 0.22 系数改为 0.07。这些是局部节点值，不是全图调色参数。
- 保持原贴图、网格和脸/身体肤色一致性。R9 修复后的裙子几何与基础物理来自 R8，不能回退更早的全片场景。
- 本地/远端同帧对照平均通道误差约 0.0001/255；这说明当前环境一致，不代表新版本 Blender 自动兼容。

## 物理：仅重算指定衣带，其他缓存回放

后端为 VMDPhysicsBake / Ammo.js 的 MMD 兼容解算，不称为官方 MMD.exe。使用 evaluated FK、原 PMX 刚体/关节、世界位置和四元数回灌，不启动 MMD GUI，不叠加 Blender rigid body world。

本片选中版本：isolated（不要选早期 whole-world 或 isolated480 实验）。240 Hz，每个 30 fps 输出步进 8 次，solver iterations=80，maxStepNum=8，gravity=[0,-98,0]，warmup=60×1/60秒。

- 沃雅妮莎：动态刚体 407–438，共 32 个。去掉辅助闭环 joint631 `右qd1`（256→423）、joint632 `左qd1`（243→407），保留腰部主锚点与链内关节。只排除这两链与内裙 group6 的碰撞，身体/腿 group0、头发 group3/4 碰撞保留。
- 奥黛塔：动态刚体 239–279、453–492，共 81 个；不修改碰撞掩码或关节，只用细步长的隔离重算。
- 其余刚体依原 R8 缓存作为运动碰撞输入回放；在求解器中使用 kinematic 代理不等于视觉冻结。最终 Blender 中只替换目标骨曲线，其他骨曲线指纹保持。
- 上述索引只适用于本机清单中的模型；其他 PMX 必须重新按骨名、刚体映射与拓扑验证。不要复制数字后直接运行。

## 用户选帧与接缝（必须复现）

统一以零基输出索引 i 计时，t=i/30；Blender scene frame=i+1。原 PNG 合成帧名为 i+1，raw PNG 名为 i，避免一帧错位。

| 索引 | 成片来源 |
|---|---|
| 0–659 | R9 原合成帧原样复用，包括 21–22 秒下蹲起身 |
| 660–674 | 目标衣带骨从 R9 向 R11 接入，其他运动与外观不变 |
| 675–948 | R11 isolated 目标衣带，其他衣发仍是 R8 缓存 |

接入权重 u=(i-659)/16，w=u²(3-2u)；目标骨 local location 使用 lerp，local quaternion 使用 slerp，逐帧插入关键帧。不是整张图叠化，不对所有骨做混合。完整接缝脚本保存在本地复现索引。

原 R11 快速下蹲时存在短暂翻折/尾部抽搐，因此用户选择恢复这一段原帧。这是经过用户选择的混合交付，不能称求解器已根治全部动作的碰撞问题。不要以“统一新版”为由覆盖该选择。

## 后期与配色

白纸外边、投影、背景、频谱、字幕和气泡/羽毛都是 2D 后期。模型内仅保留 MMD 原生细线，不把纸边做进 shader。

实际背景由脚本生成，沿用原方案“深渊红 × 天穹白”；不是从参考视频抠出的背景，也不是 Mio 字幕素材自带的背景切换。

- 酒红中心 #7A0F24，暗角 #14060C；浅底中心 #EFE9DC，边缘 #B7C4CD。
- 深海叠层深底 #0E2A30 / 浅底 #A8C5C9，天光 #F4EEDD；随机种子 241。
- light = 12.7 <= t < 14；26.3 <= t < 29.3 时覆盖为 int((t-26.3)/0.375)%2==0；其余深底。这是实际脚本规则，不是原设计列出的所有歌词时间点。
- 原 Mio 前/后字幕 alpha 层复用；浅底时按 alpha 重填深藏蓝 #1B2547，频谱改酒红。不要由背景切换推导人物灯光切换。
- 合成顺序：背景 → 氛围 → 音频频谱 → PV 后层 → 按原 metadata depth 排序的两个人物（分别纸边）→ PV 前层 → 片尾光缝等。
- 精确公式以固定版本 look.py、compose_after.py 为准。整片重合成时注意 8.7–9.45 秒的历史帧残影需要跨分片维护；本轮直接复用前 22 秒原合成帧。
