# 试片验收

机器检查成功不等于画面通过。保存 job/config/input hashes、引擎和依赖版本、操作日志与具体参数。

- 输入：原始 PMX 和贴图完整，角色与服装一致；UV 检查限定脸部 polygons。
- 节点：衣料每个 Ramp 子图有 image，材质族正确；外链存在，输出 packed 场景。
- 眼睛：虹膜、瞳孔、高光、透明边缘均可见；眨眼和转头需额外试片。
- 脸部：正面与两个侧光都有合理分界，无整脸粉黑、固定满脸阴影、头发错误投影。
- 全身：衣服、花饰、手套、裙摆完整；黑块与破面消失，金属与布料反应有区分。
- 头发：保留色带、发束轮廓和高光，避免全灰平光。
- 描边：只启用一套；脸和眼睛不能被粗黑边盖住。
- 交付：全身图不可省略；同时展示脸部，注明灯光；保存认可结果与参数，失败图另存。

状态按 generated → collected → qc_pending → accepted / rejected 记录。静态通过后再检查动画首/中/末和极端姿态。云端渲染先做同场景一帧对照，通过后扩帧；拿回并校验文件后依授权关停计费资源。

动画接续：人体曲线、材质节点和认可运镜保持；动态骨位置与旋转均回写，身体碰撞姿态与解算输入对齐，不叠加 Blender 物理。需看连续运动与独立全身检查图，不能只看脸部近景或一个角度指标。

后处理：分清原生渲染规格与超分/插帧规格。验证实际帧数、时长、音轨和整段解码，检查硬切、脸、手、描边、字幕和快速飘带的伪影。用户认可带有少量已披露伪影的试版时，记录该范围，不把它升级成任意动作都无穿模/无重影。
